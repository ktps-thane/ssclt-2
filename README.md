"สรุปภาพรวมโครงการระบบจัดรถและบริหารรถบรรทุก SSC — Version 1" และคำตอบเพิ่มเติมของเจ้าของงาน

## โครงงาน

- **สายเหนือ:** เช็คอินที่ปั๊มนครสวรรค์ ขาลงนครสวรรค์ → ห้าง/เดโป/คลังสาย 3 ขากลับรับงาน
  สมุทรสาคร (กระดาษ ASA) ปทุมธานี (นมผง PPT) วังน้อย (กระดาษปัญจพล) ส่งเข้าโรงงาน Dairy Plus นครสวรรค์
  · งาน SC Standard Can: กระป๋อง → ลำปาง แล้วรับกาแฟกระป๋องลำปาง → Dairy Plus แล้วสแตนด์บาย
- **สายใต้:** ฐานคลังพุทธมณฑลสาย 3 → ชุมพร → สุราษฎร์ → ทุ่งสง → นครศรีธรรมราช
  ส่ง Backhaul ภาคใต้แล้วกลับสาย 3
- **ประเภทงาน:** นมเหมาคัน (ห้าง/เดโป) · นมร้านค้าเหมาคันเข้าสาย 3 แล้ว Checker คัดแยก
  (ตั้งชื่อ นม + จังหวัด + ร้าน) · ขนม/เบ็ดเตล็ดรายบิลที่สาย 3 (ระบบพัสดุ)
- **คิวสายใต้ ตัดรอบ 10:00 น.:** รถมีงาน Backhaul ที่เช็คอินทันได้งานก่อน → รถสแตนด์บายที่สาย 3
  → รถ Backhaul ที่มาหลังรอบ · รัศมีเช็คอิน 500 ม. นอกรัศมีติดธง
- **ทะเบียนหลัก:** 18/22 ล้อใช้ทะเบียนหัว (เก็บทะเบียนหางและประเภทหางด้วย) · 10 ล้อใช้ทะเบียนรถ
- **ฐานหลักของรถ:** รถทุกคันวิ่งได้ทุกสาย มีฐานหลักเหนือหรือใต้ ตอนจัดรถเรียงรถฐานเดียวกันก่อน รถต่างฐานขึ้นเป็น "มาเสริม"
  · รถมีคนขับประจำ (เช็คอิน/จัดรถเลือกให้ก่อน เปลี่ยนได้) · ข้อมูลรถจริง 45 คันนำเข้าจากไฟล์ 24/9/69
- **Standard KM** นับเป็นขา ทริปหนึ่งรวมหลายขา (ขาลง / ขากลับ / วิ่งเปล่า)
- **น้ำหนัก:** ตอนจัดรถจำกัดน้ำหนักสินค้า 10 ล้อ 15 ตัน · 18 ล้อ 28 ตัน · 22 ล้อ 30 ตัน
  ตอนออกรถต้องกรอกน้ำหนักจริง และตรวจน้ำหนักรวมรถตามกฎหมาย 25 / 45 / 50 ตัน (เกินแล้วออกรถไม่ได้)
- **เวลาโหลด:** ใช้เฉพาะที่โรงงาน Dairy Plus นครสวรรค์ รถที่ลงของขากลับที่นั่นรับงานโหลดถัดไปได้
  เมื่อเวลาโหลดห่างจากเวลาลงของอย่างน้อย 2 ชม. (ลงของ 08:00 → โหลดได้ 10:00) ถ้าคนขับกด "ลงของเสร็จ" แล้ว
  ใช้เวลาลงเสร็จจริง + 2 ชม. (ลงเร็วได้โหลดเร็ว) ที่อื่นรถที่ยังติดทริปจัดงานใหม่ไม่ได้
- **ส่งงาน:** ทุกจุดส่งคนขับกด "ถึงแล้ว" และ "ลงของเสร็จ" ระบบจับตำแหน่ง GPS ตอนกด ลงของเสร็จต้องถ่ายรูปบิล
  รูปสินค้าที่ลง รูปรถว่างหลังลงของ และให้ผู้รับเซ็นบนจอ (หรือถ่ายรูปลายเซ็น) รูปถูกย่อในเครื่องก่อนส่ง
  เก็บในที่เก็บไฟล์ของลิงก์ (ความสามารถ `assets`) ในทริปเก็บแค่รหัสรูป
- **สถานที่ + Google Maps:** โรงงาน ลูกค้า เดโป อู่ เก็บพิกัดและลิงก์แผนที่ (ข้อมูลหลัก → สถานที่)
  ระบบจับชื่อต้นทาง/ปลายทางของงานกับสถานที่ (ไม่สนวรรณยุกต์ เช่น เดโป้ = เดโป) แล้วขึ้นปุ่ม "นำทาง" / "แผนที่"
  ในจุดส่งของทริป งานในทริป ออเดอร์ หน้าคนขับ (นำทางไปจุดโหลด / จุดต่อไป) และรายชื่ออู่ในหน้า Maintenance
- **GPS ติดรถ:** รถบรรทุกใช้เทเลเทค รถเล็กใช้ Forth Tracking (บันทึกในข้อมูลรถ)
  ปุ่ม "วางตำแหน่งจาก GPS" (หน้าภาพรวม / ทริป): คัดลอกหน้า "ตำแหน่งปัจจุบัน" ของเว็บเทเลเทคมาวาง
  ระบบอ่านทะเบียน เวลา ความเร็ว ชื่อจุด ตำบล/อำเภอ/จังหวัด (และพิกัดถ้าคัดลอกลิงก์แผนที่มาด้วย)
  จับคู่กับรถด้วยเลขทะเบียน (เช่น 62-6115) แล้วอัปเดตทุกคันพร้อมกัน ตำแหน่งที่เก่ากว่าที่มีอยู่จะไม่ทับ
- **รถกำลังวิ่ง:** หน้าภาพรวมและหน้าทริปบอกว่าวิ่งจากไหนไปไหน ผ่านจุดไหนแล้ว ตอนนี้อยู่อำเภอ/จังหวัดไหน และจุดต่อไป
  คนขับกดส่งตำแหน่งจากลิงก์คนขับ (GPS หรือวางพิกัด Google Maps) หรือฝ่ายจัดรถพิมพ์ชื่ออำเภอตอนโทรถาม
  ระบบหาอำเภอ/จังหวัดจากพิกัดในเครื่อง ไม่ต้องใช้บริการภายนอก
- **เวลาเข้าสาขา:** ทุกสาขาภาคใต้ต้องถึงก่อน 07:00 น. (ค่าเริ่มต้นคือเช้าวันถัดจากวันออกรถ แก้วันได้)
  บันทึกเวลาถึงได้จากปุ่ม "ถึงแล้ว" ของคนขับหรือฝ่ายจัดรถ และจากการยิงรับพัสดุที่สาขา
  เลยเวลาแล้วยังไม่ถึงขึ้นเตือนด่วน และสรุป % เข้าสาขาทันเวลารายเดือน
- **แจ้งทะเบียนโรงงาน:** ทริปที่ไปโหลดที่โรงงาน มีข้อความให้คัดลอกส่งโรงงานและปุ่มบันทึกว่าแจ้งแล้ว
  (โหลดที่คลังสาย 3 ไม่ต้องแจ้ง)
- **กำหนดส่ง:** ออเดอร์และพัสดุทุกบิลมีวันที่ต้องถึงลูกค้า · งานสัญญา = นม Dairy Plus และขนม อาหารยอดคุณ
  · เบ็ดเตล็ด = ลูกค้ารายย่อย (ค่าเริ่มต้น +3 วัน) · เตือนเมื่อเหลือเวลากระจายจากฮับไม่ถึง 3 วัน
- **ฮับสายใต้:** ชุมพร (+ระนอง) · สุราษฎร์ (+กระบี่) · ทุ่งสง · นครศรีธรรมราชทั้งจังหวัด (รถบริษัท)
  · ภูเก็ต (+พังงา) · ตรัง · สงขลา (+พัทลุง, สตูล) · ยะลา (+นราธิวาส, ปัตตานี) (Partner)

## หน้าในแอป

| หน้า | ทำอะไร |
|---|---|
| ภาพรวม | กรองตามสาย, ขั้นตอนจัดรถวันนี้, เรื่องที่ต้องดูแล, พัสดุ, สรุปเดือน, Southern Load Planning, Loaded/Empty KM, น้ำมัน, คนขับ, ต้นทุนรายรถ/Route, Maintenance |
| คิวรถ / เช็คอิน | เช็คอินพร้อมพิกัด (GPS หรือวางจาก Google Maps), กฎตัดรอบ, เลขคิว |
| ออเดอร์ | เพิ่ม/นำเข้าจาก Excel, คัดแยกนมร้านค้าที่สาย 3 เป็นออเดอร์กระจายภาคใต้ |
| พัสดุ | รับบิลขนม/เบ็ดเตล็ด, ลาเบลบาร์โค้ด 1 ใบต่อกล่อง (PDF 100×75 มม.), ยิงขึ้นรถ / ยิงรับปลายทาง / ยิงส่งลูกค้า, เก็บค่าส่งปลายทาง (ค่าขนส่งเท่านั้น) |
| จัดรถ | Order → Route → Vehicle Matching → Maintenance Check → Dispatch แยกสาย รวมพัสดุตามปลายทางลงรถได้ ตรวจน้ำหนัก เวลาโหลด และกำหนดส่ง |
| ทริป | แจ้งทะเบียนโรงงาน, หลายขาต่อทริป, ออกรถ (น้ำหนักจริง)/ปิดทริป, เลขไมล์, Variance, น้ำมัน Feed Card, เบี้ยเลี้ยง, ทางด่วน, รายได้รวมค่าส่งพัสดุ |
| Maintenance, ข้อมูลหลัก, หางสำรอง, ค่าตั้งค่า, ร่างระบบเช็คอิน, รอข้อมูล | ตามชื่อ |

ข้อมูลจริงยังไม่มีรถและคนขับ (รอไฟล์) จึงเปิดเป็น **โหมดทดลอง** อัตโนมัติด้วยข้อมูลสมมติที่เก็บในเครื่องผู้ใช้
ข้อมูลจริงตอนนี้มีจุดเช็คอิน (คลังสาย 3, ปั๊มนครสวรรค์ ยังไม่ปักหมุด), ฮับปลายทาง 8 จุด และเส้นทางจากเอกสารและคำตอบของเฮีย

## โครงสร้าง

- `app/index.html` หน้าเดียวทั้งแอป (HTML/CSS/JS ล้วน ไม่มี build) เผยแพร่เป็น Claude Artifact
  ที่ใช้ความสามารถ `db` (ฐานข้อมูลที่ทุกคนที่เปิดลิงก์เห็นร่วมกัน), `user`, `downloads` (ไฟล์ลาเบล PDF)
  และ `assets` (รูปส่งงาน ทำให้ลิงก์แชร์ได้เฉพาะในองค์กร/คนที่เชิญ แชร์สาธารณะไม่ได้)
  โหลด JsBarcode 3.11.6 และ jsPDF 2.5.1 จาก cdnjs ไฟล์นี้ไม่มี `<!doctype>`/`<head>` เพราะตอนเผยแพร่ระบบจะครอบให้
- คอลเลกชัน: `vehicles`, `drivers`, `sites` (คลัง/จุดเช็คอิน/สาขา), `routes` (ขา), `orders`, `trips` (มี `jobs`),
  `checkins`, `parcels`, `trailers`, `config/settings`, `config/pseq-<วันที่>` (ตัวนับเลขพัสดุรายวัน)
- เลขพัสดุ `S` + ปีเดือนวัน (ค.ศ. 2 หลัก) + ลำดับ 4 หลัก เช่น `S2610130001` บาร์โค้ดกล่อง `S2610130001-01`

  (จุดที่ห่างเส้นแบ่งอำเภอไม่ถึงครึ่งกิโลอาจได้อำเภอข้างเคียง)

## ข้อจำกัดของแบบร่าง

- ในหน้าต่าง Claude เบราว์เซอร์อาจไม่ให้อ่าน GPS และใช้กล้องสแกนไม่ได้ จึงใช้การวางพิกัดจาก Google Maps
  และเครื่องยิงบาร์โค้ด (USB/บลูทูธ) แทน ระบบจริงบนเว็บบริษัทหรือ LINE จะใช้ได้เต็มที่
- เวลาเช็คอินใช้นาฬิกาของมือถือ ระบบจริงควรใช้เวลาจากเซิร์ฟเวอร์
- ตำแหน่งรถมาจากคนขับกดส่งเอง หน้าเว็บติดตามเบื้องหลังไม่ได้ ถ้ารถมี GPS ติดรถ (ตามกรมการขนส่งทางบก)
  ควรต่อ API ของผู้ให้บริการเพื่อดึงตำแหน่งอัตโนมัติ
- ผู้ใช้ทุกคนต้องมีบัญชี Claude และได้สิทธิ์บันทึกจากเจ้าของลิงก์
- ฐานข้อมูลของลิงก์เก็บได้ 25,000 รายการ เหมาะกับช่วงทดลอง ถ้าใช้จริงทั้งบริษัทควรย้ายขึ้นฐานข้อมูลของบริษัท
